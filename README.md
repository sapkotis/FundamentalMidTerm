# Programming Fundamentals - Midterm Exam

## Overview
This repository contains a comprehensive midterm examination for a Programming Fundamentals course. The exam covers essential concepts in computer science and programming.

## Contents

- **MIDTERM_EXAM.md** - The complete exam with all questions (100 points + 5 bonus points)
- **ANSWER_KEY.md** - Detailed solutions and grading rubric for instructors

## Exam Structure

### Part 1: Multiple Choice (20 points)
10 questions covering fundamental programming concepts including:
- Algorithm complexity
- Data structures
- Basic syntax
- Programming principles

### Part 2: Short Answer (20 points)
5 questions requiring brief explanations of:
- Data structure differences
- Programming concepts
- Error types
- Complexity analysis

### Part 3: Code Reading and Analysis (20 points)
2 problems focused on:
- Understanding recursive functions
- Debugging code
- Code analysis skills

### Part 4: Coding Problems (40 points)
3 programming challenges of increasing difficulty:
- String manipulation (palindrome checker)
- Recursive/iterative algorithms (Fibonacci)
- Data structure manipulation (vowel counting)

### Bonus Question (+5 points)
Advanced array manipulation problem

## Topics Covered

- **Data Structures:** Arrays, Linked Lists, Stacks, Queues, Hash Tables
- **Algorithms:** Sorting, Searching, Recursion
- **Complexity Analysis:** Big O Notation
- **Programming Concepts:** Variables, Functions, OOP basics
- **Problem Solving:** Debugging, Code reading, Logic

## For Students

1. Review the exam format in `MIDTERM_EXAM.md`
2. Time limit: 90 minutes
3. Total possible points: 105 (including bonus)
4. Bring your knowledge of fundamental programming concepts
5. You may use pseudocode or any programming language for coding questions

## For Instructors

1. The `ANSWER_KEY.md` file contains detailed solutions
2. Grading rubrics are provided for each question
3. Partial credit guidelines are included
4. Exam can be administered as:
   - Paper-based exam
   - Digital assessment
   - Take-home assignment (adjust time accordingly)
